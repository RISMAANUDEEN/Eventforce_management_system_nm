**EventForce Management System**
    EventForce Management System is a Salesforce-based event management solution designed to simplify and centralize event planning and management.

**Project Overview**
    The system helps manage Events, Clients, Venues, Vendors, and Feedback in one centralized platform. It also automates important tasks like event reminders, venue availability updates, cancellation approvals, and prevents double bookings.

**Key Features**
    -> Event and Client Management
    -> Venue and Vendor Management
    -> Automated 3-Day Event Reminder
    -> Venue Availability Management
    -> Double Booking Prevention
    -> Cancellation Approval Process
    -> Reports and Dashboards
    -> Role-Based Security

**Technologies Used**
    -> Salesforce CRM
    -> Apex
    -> Apex Triggers
    -> Salesforce Flows
    -> Lightning App
    -> Reports & Dashboards
    -> Custom Objects & Relationships

**Main Modules**
    Event | Client | Venue | Vendor | Feedback | Event Vendor
